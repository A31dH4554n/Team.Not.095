FAQ

Is it safe to run these scripts?

They change system settings, so treat them with care. Create a restore point, read each script, start with the basic cleaning and latency tweaks, and keep anything marked Advanced for when you understand what it does.

Can I undo the changes?

A restore point lets you roll back most changes. Back up first, because registry tweaks and some scripts do not always have an automatic undo.

Which Windows versions are supported?

The toolkit targets Windows 10 and 11. Some files are version-specific, so check the file name and notes before running.

Why are some items marked Advanced?

They disable protections such as Defender, Spectre/Meltdown mitigations, DEP or Windows Update. That can improve speed on some systems, but it reduces security.

Where can I get the files?

Use the Get the full collection button in the library, or open the Discord channels and Mega folders in the Resources section.
